작성자: 마케팅 (초안, 대표 검토 후 게시)

> 이 문서는 iOS App Store / Google Play 정식 출시에 맞춰 작성한 SNS 홍보 게시물 초안입니다.
> `docs/store-listing.md`의 톤 원칙(운세·사주·점 대신 성향·참고용·살펴보다 어휘 사용, 검증되지 않은 수치·후기 미기재)을 그대로 따랐습니다.
> 게시 전 링크·이미지·최종 표현은 대표 검토 후 확정해주세요.

## 0. 공통 전략 메모

**목표**: 정식 출시 소식을 자연스럽게 알리고, 설치/첫 기록 작성까지 유도

**타겟 페르소나**: 20~30대, 하루를 바쁘게 보내고 나면 "오늘 뭐 했는지 기억이 잘 안 난다"고 느끼는 사람. 일기를 써보고 싶었지만 매번 "거창하게 써야 할 것 같아서" 시작도 못 하고 포기했던 경험이 있음.

**핵심 메시지**: 마음을 기록하고 성장하는 시간 — 사진·음성으로 가볍게 남기고, 짧은 질문을 따라가며 하루를 정리하고, 성격 검사로 나를 조금 더 알아가는 것.

**채널별 차이**:
- Threads: 짧고 담백하게, 공감되는 한 장면으로 시작, 해시태그 1~3개
- Facebook: 조금 더 설명적으로, 기능 맥락을 풀어 쓰고 공유/저장 유도 문장 포함

**공통 금지 사항** (store-listing.md와 동일 원칙):
- "운세", "사주", "점", "진단" 표현 금지 → "성향", "참고용", "살펴보다", "알아가다"로 대체
- 실사용자 수, 후기, 별점 등 검증되지 않은 수치 금지
- 과장 표현("최고의", "무조건", "완벽한" 등) 지양

**지표(참고용)**: 게시물별 도달/참여(좋아요·리포스트·댓글), 링크 클릭 수, 설치 전환(가능하면 UTM으로 구분). 초기엔 유료 광고 없이 자연 도달로 반응을 보고, 반응 좋은 주제/톤을 다음 콘텐츠 캘린더에 반영 추천.

## 3. 게시 전 체크리스트

- [ ] [App Store 링크] / [Google Play 링크] 플레이스홀더를 실제 스토어 URL로 교체
- [ ] 성격 검사 관련 게시물(Threads #1 전체소개 언급 없음 / Facebook #2)에 면책 문구("참고용 콘텐츠이며 과학적으로 검증된 진단이나 예측이 아닙니다") 누락 여부 재확인
- [ ] "운세/사주/점/진단" 표현 재검토 — 현재 초안엔 없음, 수정 시에도 유지
- [ ] 실사용자 수·후기·별점 등 수치 추가되지 않았는지 최종 확인
- [ ] 이미지/스크린샷 첨부 시 store-listing.md 체크리스트의 스크린샷 소재(빠른 캡처/마음 기록/오늘을 기억할래/저널/성격 검사 결과)와 통일된 비주얼 사용 권장
- [ ] Threads는 게시물당 해시태그 1~3개로 제한, Facebook은 해시태그 생략 또는 최소화(설명형 톤 유지)
- [ ] 게시 순서 제안: Threads #1(전체소개) → Facebook #1(전체소개) 선게시 후, 2~3일 간격으로 기능별 게시물 순차 발행
